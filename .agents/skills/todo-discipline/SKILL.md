# Turn-Scoped TODOs

Use the `todo` tool only for a bounded effort that has multiple meaningful steps, dependencies, an explicit task list, or a real reason to span turns. Skip it for a single edit, lookup, test, answer, or other trivial action.

- Scope each task to the specific effort underway. Do not create backlog items, vague reminders, or speculative future work.
- Create the smallest useful task list, then mark the active task `in_progress` before starting it. Keep only one task in progress.
- Mark each task `completed` immediately when its specific effort finishes— in the same turn whenever possible. Do not leave completed work open until the end of a larger project.
- If a task is abandoned, invalid, or duplicated, delete it instead of leaving stale TODO state. If it is genuinely blocked, keep it open only with an actionable blocker and close it as soon as the blocker clears.
- Before ending a turn, check for TODOs created for this effort. Close finished tasks; TODOs should rarely outlive the turn that created them.
